# 2026-07-13 工作日志

## 修复：Phase39 mergeOldToolPairs 写入 string content 破坏 Message 契约

### 错误
`[internal] message.content.map is not a function`

### 根因
`mask-tool-observations.ts:225` — `mergeOldToolPairs` 新函数创建消息时用了 `content: lines.join('\n')`（string），但 Message 类型要求 `content` 是 `ContentPart[]`。下游 10+ 处 `.content.map()` 调用因此崩溃。

### 修复
改为 `content: [{ type: 'text' as const, text: lines.join('\n') }]`

## 修复：Phase39 mergeOldToolPairs 设 toolCalls:undefined 崩 projector

### 错误
`[internal] Cannot read properties of undefined (reading 'length')`

### 根因
`mergeOldToolPairs:225` 设 `toolCalls: undefined`，`projector.ts:97` 无保护访问 `message.toolCalls.length`

### 修复
`projector.ts:97` 加 `!message.toolCalls ||` 守卫
