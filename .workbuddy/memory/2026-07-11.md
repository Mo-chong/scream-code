## 修复：UI 输入框自动发信 — PersistentSummaryInjector 每步注入

### 根因
旧内联代码（session summary 和 persistent summary）已被用户手动注释禁用（`turn/index.ts:833-848`），但 DynamicInjector 版本把它们重新激活了：

- **`PersistentSummaryInjector.getInjection()`** 在**每一步**都检查 `ILR > 0`，一旦有被 mask 的 tool 结果就注入一条 `role:'user'` 消息
- 旧内联 `updatePersistentSummary()` 只在 `stepNumber === 1` 触发（且被注释了）
- 每步注入的 user-role 消息 → `pushHistory()` → `records.logRecord()` → TUI 状态更新 → 输入框闪烁

### 修复
`persistent-summary.ts`:
- 新增 `getResidualConfig()`: weight=0.7, decay=0.85, thr=0.15, minStepGap=3
- `getInjection()` 加 `step !== 1` 守卫（仅每轮第一步触发，与旧代码一致）
